# 📌 Project Overview

This is a responsive **Weather Application** built using **React** and **Material UI**.

The application allows users to search for any city and view the current weather conditions in real time.

The app fetches weather data from a weather API and displays important information such as:

- Temperature  
- Humidity  
- Weather conditions  

The interface is designed using **Material UI components** to provide a clean and responsive user experience.

# 🚀 How to Run the Project Locally

### 1️⃣ Clone the repository

```
git clone https://github.com/CODER-RAHUL9038/WEB-DEVELOPMENT-PRACTICE.git
```

### 2️⃣ Navigate to the project folder

```
cd WEB-DEVELOPMENT-PRACTICE/REACT/Material-UI/weather-app
```

### 3️⃣ Install dependencies

```
npm install
```

### 4️⃣ Run the development server

```
npm run dev
```

The application will run at:

```
http://localhost:5173
```

# ⚠️ Challenges Faced

One of the challenges during development was handling API responses correctly when users search for different cities.

The application needed to fetch new data dynamically and update the UI without reloading the page.

Another challenge was organizing the UI using Material UI components while keeping the component structure reusable and maintainable.
