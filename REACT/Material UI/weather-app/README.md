## Project Overview

This is a responsive Weather Application built using **React** and **Material UI**.  
The application allows users to search for any city and view the current weather conditions in real time.

The app fetches weather data from a public weather API and displays key information such as temperature, humidity, and weather conditions in a clean and user-friendly interface.

This project helped me practice **API integration, React component structure, and building modern UI using Material UI**.
